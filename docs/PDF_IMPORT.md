## Suggested workflow for another upload

1. Render and inspect every page so diagrams and stacked equations are not lost.
2. Extract each method into the same `Trick` shape used by the app.
3. Keep the original meaning, but rewrite explanations in plain language for students.
4. Add at least one worked formula and three ordered learning steps.
5. Add a quiz question only when the answer and explanation have been checked.
